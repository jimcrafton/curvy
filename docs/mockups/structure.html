How these relate

  • Outline: layers, groups and shapes as one tree, each row with a thumbnail, visibility and lock, and a count. It is a view of the same structure the node graph shows as subnets: a layer or group is a subnet, a shape row is a node. Click a row to select, click the artwork to find the row, type to filter. Opens with L, as a translucent dock like the property boxes.
  • Layer strip: for pen work the full outline is too much, so a narrow strip of coloured chips shows only the layers: the active one, visibility, and a flyout of names. Hold L and move up or down to change the active layer without leaving the drawing (the same hold-key scrub as properties), or pick from a layer ring on the barrel button. New shapes go to the active layer, so this is the one structural control you need while drawing.
  • Document card: everything about the document as a whole: name, description, author, page size and units, resolution, colour mode, background, the artboard list, and counts (shapes, nodes, points, fonts, linked images). It opens from the "..." hub of the document ring, and is the place metadata lives so the canvas stays clear.
  • Artboards on the canvas: artboards are shown where they are, with their name and size above them, and selected by clicking, so there is no separate list to maintain; the document card lists them for reordering and bulk changes. A "fit artboard" key and an artboard ring would jump between them.

Open questions

  • Does a shape row show its node chain (e.g. Star > Transform > Copy) inline, or only when selected? Inline costs width.
  • Layers and groups both become subnets; should the outline show a different icon for "layer" (a place to draw) and "group" (a unit that moves together)?
  • With hundreds of rows the outline wants the same filter, thumbnails and virtual scrolling as the node view.
