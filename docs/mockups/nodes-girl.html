The node graph at a realistic size

The graph is how the document is stored; the canvas, the node view, the property boxes are all views of it. This page shows one document at a realistic size: an illustration with 341 shapes, 5434 points and 56 fill colours, so about 416 nodes as an artist would have built it. The source SVG is flat and only supplies the shapes, so the grouping (night sky, hair, birds, face and so on) is a guess at how someone would have organised it while drawing. Switch between Flat (every node at once) and Grouped (subnets; double-click one to enter it). Scroll to zoom, drag the background to pan, type to filter. Click a node to see its shapes in the artwork.

What this shows about scale

  • Flat is a hairball, and expected to be. Zoomed out the individual nodes stop being readable, so they drop to their thumbnails (no text, no ports). A graph that big is something to search and select, not read.
  • Grouping has to happen as the user works. Every shape drawn adds nodes, so Group, layers and "make a subnet" are what keep the graph readable: ten group nodes with a thumbnail, a count and a colour strip give an overview you can take in, and entering one shows its paths and the Fill nodes they feed. Grouping should be as cheap as in a drawing program (select, press a key), and a layer or group in a loaded file becomes a subnet.
  • Every node is its own thumbnail. Because nodes carry geometry, a card shows what it makes, which is the main way to recognise one among hundreds.
  • Selection works both ways. Selecting a node highlights its shapes in the artwork (everything else dims), and filter text does the same for matches; picking on the canvas should likewise select the node.
  • Navigation tools needed: Fit, a minimap, breadcrumbs, and the filter box. The graph panel needs more room than a drawer once graphs look like this, so it would use the lens (hold N) or a large floating window, with the drawer kept for small graphs.
  • Not shown: layout is a simple column layout here, so real auto-layout, collapsing a chain into one node, and a palette node feeding many Fill nodes would all reduce the node and wire count further.
