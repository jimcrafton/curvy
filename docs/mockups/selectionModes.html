Selection modes

Drag on empty canvas with the primary button to select what the shape fully contains, with the secondary button (right mouse, pen barrel) for everything it touches. Pick the region shape in the card: Rectangle, Ellipse, Freehand (drag a loop) or Polygon (click corners, click the first one, double-click or Enter to close, Esc cancels). Shift adds, Alt subtracts. The lower card selects by a property instead of by area. Also: Ctrl+A all, Esc clears, Tab / Shift+Tab cycles.

How it works (proposal)

  • Two buttons, no modifier. The primary button is "fully inside", the secondary button is "touches", so a pen can do both (barrel button = secondary). This replaces the direction rule of the older Selection and transform mock (left to right contained, right to left touching), which needed a precise drag direction. If the secondary button is wanted for something else (the ring), untick Secondary button picks what it touches: both buttons then use the one Containment setting, kept in the Select tool's options card (the small option box curvy v1 had for ring items).
  • Region shapes. Rectangle and Ellipse are a drag from corner to corner; Freehand closes itself when the button is released; Polygon is click by click and its first click fixes the button, so the whole polygon is "inside" or "touches". The region is tested against the real outline (sampled), not the bounding box; an open line counts as touched when the region comes within half its stroke width. The status badge says N shapes, inside or touching.
  • Where a marquee can start. Only on empty canvas. A press on a shape is a click (select / step up) or, later, a move, never a marquee. A press with no drag is still the click that clears. Space still pans.
  • Select by. The card builds a value list from what the document holds and selects every shape that has the value. It works on the engine data that exists today, so it needs no new storage:
    PropertyWhere it comes from
    TagNode::tags() of the node that made the shape, and of the layer or group around it (so tagging a group selects all of its shapes). Added with the Node panel's tags field or node.add_tag.
    Fill / Stroke colourthe primitive attributes fill.r g b a and stroke.r g b a the Fill and Stroke look nodes stamp on the geometry. Compared with a small tolerance.
    Stroke widthstroke.width, rounded to 0.5.
    Typethe producing node's type (circle, path, python, ...).
    Layerthe enclosing layer object.
    Within: the whole document, the level you are in, or the current selection (narrow a selection down).
  • One query behind everything. shapesWhere(artwork, predicate) returns keys; the marquee, the card and the Python calls (doc.shapes_in_rect, doc.select_where(tag=..., fill=..., stroke_width=...)) all go through the same result and the same SelectionModel add / subtract / replace.
  • Not mocked: select by custom attribute from a script (a Python predicate), "same fill and stroke" combined, invert, saved selections.
