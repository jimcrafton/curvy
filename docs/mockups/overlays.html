Overlays: perspective guides and tracing paper

Overlays help you draw and never reach the export. Two kinds here: a perspective guide (one, two or three vanishing points on a horizon) and a reference layer (an imported or sample image plus reference shapes). Try it: with the Pen tool click to draw lines; hold Shift to lock a segment to the nearest perspective direction, or hold 1, 2, 3, 4 to pick one. In the Guides tool drag the vanishing points and the horizon. Tap Space for the overlay ring, hold O and move up/down to fade the active overlay, hold H to peek without overlays.

How it works (proposal)

  • One idea, two kinds. An overlay is something that helps you draw and has the Reference role: it is never exported or printed, and its visibility, opacity and above/below order are its own. Parametric guides (perspective here; isometric grids and symmetry axes would be the same kind) are small nodes with draggable handles that output guide geometry and no artwork. A reference layer holds an image and shapes; the shapes are ordinary paths with the Reference role, so they can be promoted to art ("To art").
  • Perspective guide. One, two or three vanishing points. The first two sit on the horizon (drag a point to slide it along it, drag the horizon's amber handle to move it); the third is free. Rays fan out from each point at a chosen step, 2-point can add verticals. In 1- and 2-point perspective the verticals stay vertical, so "vertical" (and in 1-point "horizontal") are extra directions in the picker.
  • Constraining the pen. Each new segment starts at the last point. Hold Shift to lock it to the nearest direction (the amber ray shows which one), hold 1..4 to choose the direction yourself (the keys are listed in the hint bar), or leave soft snap on and a segment within a few degrees of a ray snaps by itself. Without a perspective guide Shift falls back to 45 degrees.
  • Snapping to references. Reference shapes, art and the vanishing points are snap sources. On a constrained ray the point lands on the intersection of the ray with a reference or art segment, or on an anchor that sits on the ray; unconstrained it snaps to an anchor, then to the nearest point on a segment, then to an intersection. The badge names what it snapped to. Each overlay has its own snap switch.
  • Tracing paper. The reference image sits between the paper and the art (or above everything, per overlay) at an adjustable opacity; when unlocked, drag it in the Guides tool, scale it, flip it, or fit it to the page. "Draw into: Reference" sends the pen's strokes to the reference layer instead of the art, so you can sketch construction lines that later snap and never export. "Sample photo" is a generated street corner whose edges converge on the default vanishing points, so turning the guide on shows the match.
  • Export preview. The "preview export" switch (and the download button) shows what the Export node would produce: the page with only art, no guides, no reference image and no reference shapes. Hold H to peek without overlays while drawing.
  • Space ring. Tap Space (or the barrel button) for the overlay ring: 1-point, 2-point, 3-point, Image, Draw into (Art / Reference), Snap, Hide overlays, Remove the active overlay. In the document ring this would be the "Rulers · grid" slot becoming Overlays. Hold O and move up/down to change the opacity of the active overlay.

What this means for the graph and the code

  • Overlays are nodes with the Reference role. The snap system asks every visible overlay with snapping on for snap sources (points, segments, rays), the same query that artboards use to snap to each other, and the pen and direct tools use the result. The Export node skips anything with the Reference role, so it needs no special case.
  • The perspective constraint is a direction picker over a list of rays plus a projection of the pointer onto the chosen ray, then a ray-versus-segment intersection test against the snap sources. It is cheap, but a large reference drawing needs a spatial index so the pen stays smooth.
  • Image storage: embedding bloats the SVG and linking breaks when the file moves, so embed by default with a size warning. An image also needs a scale calibration (set two points to a known distance) to match real units; this mockup scales by a slider.
  • Perspective guides pair with the planned deformers: a perspective warp is a deformer node, and onion skin for animation would be another reference overlay.

Not in this mockup

  • Isometric grids and symmetry axes, several perspective guides at once (the data allows it), curved strokes (the pen here makes straight segments), moving or calibrating the image by two points, per-overlay layers in the outline, and the overlay panel inside the document card.
