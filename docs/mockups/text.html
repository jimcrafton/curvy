Text and fonts

Text is a node (Text › Glyphs › Fill), not a separate kind of object. Try it: with the Text tool click empty canvas for point text, drag for area text (it wraps), or click the grey curves for text on a path. Tap F over a text object for the font card, or hold F and move up/down to scrub through fonts. Hold S size, K tracking (kerning when the pen sits between two letters), L leading, E weight, N width.

Tool

How it works (proposal)

  • Creating text (T). Click empty canvas = point text (grows as you type), drag = area text (wraps in the box, a red + marks overflow), click a curve = text on that path (the badge says so on hover). Click existing text to edit it. Esc or clicking elsewhere finishes; empty text disappears.
  • Fonts (F). Tap F over text for the font card: search, filters (Document, Recent, Favourites, Serif, Sans, Mono, Script, Display), each family drawn in itself. Hovering a row previews it on the real text, click keeps it (one undo step), arrows and Enter work too. Hold F and move vertically to step through the installed fonts with the text updating live; release keeps it. Missing fonts are listed in the HUD with a Replace button that opens the same card.
  • Space ring. Tap Space (or press the barrel button) over text for the text ring: Edit, Font, Style (cycles Regular / Bold / Italic, or the weight of a variable font), Align (cycles), To path / Detach, Outlines, Fill (cycles the swatches) and Clear kern; the hub "Text ..." is where the full character and paragraph panel will open. Over empty canvas or an empty curve it is the creation ring, where only the Text slot works in this mockup. While you are typing Space types a space, so use the barrel button there.
  • Kerning, three ways. (1) In the text, as in Illustrator: with the caret between two letters Alt+←/→ moves the pair by 20/1000 em, Ctrl+Alt makes it five times that; with a range selected the same keys add the step after every selected letter (tracking over a range). An amber tick and the pair label flash at the gap. (2) Hold K with the pen between two letters and scrub. (3) The kerning view toggle in the header puts a tick on every gap of the selected text; drag a tick sideways to kern that pair directly, and the values are listed in the Glyphs box. Auto kern (Metrics / Off) is the font's own pair kerning underneath, and the overrides are added on top of it. Optical kerning (spacing from the letter shapes) is not mocked.
  • Hold-key scrubbing follows the rule from the other mockups: the object under the pen (or the selection), vertical travel, release commits as one step, Shift snaps size to common sizes. S size, K tracking, L leading, E weight, N width (the last two only for a variable font such as Bahnschrift). With the pen between two letters K changes the kerning of that pair instead, and an amber tick marks which gap. Letters are placeholders like the others.
  • Select tool (V). Drag text to move it; area text has handles to resize the box; text on a path has an amber handle at its start that slides it along the curve. Double-click text to edit.
  • Typography guides (toggle, and shown while scrubbing size/leading): baseline, x-height and cap-height lines measured from the actual font.

What this means for the graph and the code

  • A text object is a Text node (string, font, style or variable axes, size, tracking, leading, alignment, box or path input) feeding a Glyphs node that outputs one primitive per glyph with outline geometry and point/primitive attributes (advance, kerning, baseline shift, rotation, glyph index). Hand-set kerning is just an attribute override on the glyph, in the same spirit as the pen's pressure attribute, so downstream nodes can modify it (a wave or random-baseline node would be an ordinary attribute node).
  • Text on a path is the same Text node with a path input: the shared bezierPath node, a start offset and a side. Editing the curve with the pen moves the text; the text never owns the curve.
  • Convert to outlines is a bake like fitCurve: the Glyphs node becomes plain bezierPath nodes, the string and font are dropped, editing is blocked with a hint, and undo brings the text back.
  • Fonts are document resources (the Fonts tab of the document card): used, installed, embedded or missing. A missing font keeps its name and renders with a substitute until replaced.
  • Risk to check before building: Blend2D loads fonts and returns glyph outlines, but its shaping is basic (I believe kerning only; not verified), so ligatures, complex scripts and right-to-left text may need HarfBuzz as a separate dependency.

Not in this mockup

  • OpenType features (ligatures, small caps, stylistic sets), paragraph and character styles, threading text between boxes, vertical and right-to-left text, hyphenation, per-character selection styling (bold one word), a glyph palette for alternates, and text on a closed shape (inside/outside). The sample draws with the browser's text engine, so wrapping and kerning here are approximations of what curvy would do.
