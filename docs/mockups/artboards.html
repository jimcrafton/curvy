Artboards and export

An artboard is a node (a named rectangle with a background) that crops the shared canvas; export is a node too, so the export settings live in the document. Try it: with the Artboard tool drag on the grey workspace to make one, drag one to move it (its artwork follows), drag the handles to resize; tap Space over an artboard or over the workspace for the rings; hold W or H over an artboard and move up/down to set its size (Shift snaps to common sizes). Open Export and Save a file: SVG, PNG, JPG and WebP are really produced and downloaded.

How it works (proposal)

  • Artboards are crops, artwork is shared. All artwork lives on one canvas; an artboard is a named rectangle (position, size, background, bleed) that decides what an export contains. Artwork can overhang an artboard (the green hill below the poster) and is cut off in the export. An object belongs to an artboard for moving purposes when its centre is inside it; the header switch decides whether moving or duplicating an artboard takes that artwork with it.
  • Making and editing. Artboard tool (O): drag on the workspace to create, drag an artboard to move it (Alt-drag duplicates it with its artwork), drag the handles to resize, edges snap to the other artboards (amber guides). In the Select tool the artboard is picked by clicking its empty area, and moved by its label. The HUD holds the name, presets, X/Y/W/H, orientation, background (white, transparent, dark), bleed and the artboard's order, which is also the PDF page order.
  • Space rings. Over an artboard (in the Artboard tool always; in the Select tool an object under the pen gets the object ring instead, so a full-size background rectangle can be passed by using the artboard's label): Export, Quick export, Fit to art, Duplicate, Rename, Orientation, Background, Delete. Over the grey workspace (the document ring, the same slots and keys as main.html state 3b): New artboard A, New document N, Open, Save, Export E, Place image, Fit 0, Rulers · grid. Open, Save and Place image are greyed out here. Arrange all is a button in the artboard side box. The barrel button opens the same rings.
  • No document open: the New ring. Close the document (button above) and the workspace is empty; tap Space on it (or press the barrel button) and the New ring appears: four default sizes (Letter, A4, Full HD, Square 1080, one tap creates the document), Open, and Recent (the sample). Its hub, Create…, opens the full New Document dialog: name, size presets or a custom size in px / in / mm, orientation, number of artboards, background and colour mode, with a preview. With a document open, the document ring's New document slot opens the same New ring, and its New artboard slot opens an Artboard ring of the same four sizes plus Same size (as the selected artboard) and Custom, placed centred on the pen. So the empty-workspace press is about documents when none is open and about artboards when one is. The view zooms to fit the new artboards.
  • Hold-key size. W and H over an artboard scrub its width and height with vertical travel; Shift snaps to common sizes, and the card shows the preset it matches.
  • Export card. Left: what to export (everything, or only the selection), a checklist of artboards and of objects marked Export as asset. Right: the outputs, each a format + scale + options (SVG responsive / outline text; PNG and WebP transparent; JPG and WebP quality; PDF with bleed), with presets (Web, App icon, Social, Print) and a naming template. Below, the resulting files with thumbnail, pixel size and the real byte size; Save downloads one file, Export N files all of them.
  • The export settings are nodes. The outputs, the checked artboards and the template belong to the document (an Export node reading the artboard and asset nodes), so reopening the file and pressing Quick export or Export all repeats the same export. Marking an object as an asset adds it to that set.

What this means for the graph and the code

  • Artboard node: name, rect, background, bleed, clip. It is an output the Export node and the document card's artboard list both read; the order of the nodes is the page order. Artboards do not own geometry, so moving one with its artwork is an editing convenience that moves the selected nodes' transforms, not a parent/child relationship.
  • Export node: input = a set of artboards and/or objects, parameters = the output rows and the name template, output = files (no geometry). It evaluates on demand, never during editing. Rasterising goes through the same renderer as the canvas (Blend2D) at the requested scale; SVG export needs the stroke-outline and text-to-path steps from the stroke and text notes, plus the embedded graph metadata as an option.
  • The sample does the real thing in the browser: it builds a cropped SVG per file, and rasterises it through a canvas for PNG, JPG and WebP, so the byte sizes shown are real. PDF is listed but not produced here.

Not in this mockup

  • PDF output, colour profiles, slices (an export region that is not an artboard), pan and zoom (fixed at 60%), artboard presets editing, the document card's artboard list, importing, a folder picker (the browser decides where files go), batch rename, and a progress view for large exports.
