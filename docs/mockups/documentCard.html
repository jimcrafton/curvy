The document card

  • What it is: one floating panel for everything about the document as a whole, so the canvas and the docks stay clear. In newui it is a TabControl with one TabPage per tab (Document, Swatches, Library, Fonts), inside a small titled frame. It sits over the canvas, can be dragged by its title and remembers its place and its last tab.
  • Opening it: the Document button in the top bar or a click on the document name chip; Esc or ✕ closes it. Later also the "…" hub of the document ring. Opening it from a feature (a swatch's "Used by", a missing font) goes straight to the right tab.
  • It does not block the canvas: the canvas keeps working beside it, which is what makes "Select them" and a live recolour useful.
  • Modified flag: any edit made here (a name, a swatch, a palette) is a normal undo step and sets the document's modified flag, so the name chip in the top bar (and the window title) gets its "*" like any other edit. Try renaming the document or a swatch.

Tabs

  • Document (sketched): name, description, author, page size, units, resolution, colour mode, background, the artboard list and counts. Built after Swatches.
  • Swatches (this mockup, layout C): every palette as a row with its colours as a strip (click to activate, Recent last), then the active palette's grid, a details box and the colours in no palette.
  • Library and Fonts (sketched): symbols, patterns, styles, brushes; fonts used with Replace for a missing one. Not planned yet.

Swatches tab, what is live here

  • The canvas has 20 shapes in three groups. Used by counts them, Select them outlines them on the canvas, and the count is the same one the app would read from the colour rows.
  • Linked swatches (white corner): Ember, Plum and Paper. Type a new hex for one and every shape tied to it follows at once; a plain swatch only changes itself. Unlinking leaves the shapes as they are.
  • In use, in no palette lists colours on shapes that no swatch has; + Add puts one in the active palette.
  • New palette from image: the "…" menu opens a dialog with the sample pictures standing in for a file; median cut with Colours, Order by, Merge near-duplicates and Ignore near-white/black, a live preview, then Create palette (one undo step, becomes active).
  • The strip in the colour card and this tab are views of the same palettes (one controller), so they never disagree.
