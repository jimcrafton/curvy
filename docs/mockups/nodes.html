The node graph inside the minimal UI

The graph is a layer under the drawing, not a separate application. Most of the time you never see it: a live shape's parameters are in the property box. When you want the graph, it opens as a translucent drawer over the bottom of the canvas, so the artwork stays in view and shows the display node as you edit. How it fits

  • Peek: selecting a live shape shows its pipeline as a small chip beside it (Star, Transform, Copy). Tap a node name to select that node (its parameters appear in the property box); tap the chip's edge, or press N, to open the drawer. This is as much graph as most people ever need.
  • Drawer: the graph editor docks to the bottom as a translucent drawer between the toolbar and the property box, drag its top edge to resize, N toggles it. The canvas above keeps showing the display node, so every change is seen immediately. Selecting a node selects its object, and the other way round.
  • Property box = parameters of the selected node. Same boxes as the rest of the UI. Each parameter has fx (switch to an expression) and key (keyframe at the playhead), as in the jitnodes editor. Scrub keys work over a parameter too.
  • Pen on the graph: drag from an output port to wire; drag a wire off an input to detach it; drop a wire on empty space (or tap Space) and the add-node ring opens there, with the new node wired in on pick. Barrel button over a node gives the node ring (display, bypass, rename, delete). Middle-drag or two-finger drag pans; pinch or wheel zooms.
  • The ring's categories here (Shape, Modify, Copy, Math, Attributes, Time, Group, More) are placeholders until they are taken from the registered node types.

For the code

  • jitnodes' GraphController and ParameterPanel are UI-toolkit-free but talk to EditorModel (own History). They use about twenty model calls, so extract a small interface that both EditorModel and GraphDocument implement; edits then go through curvy's shared undo stack.
  • GraphCanvas is a newui SubView, so it can live in the drawer as it is, with pen-specific input (ring on wire drop) added on top.
